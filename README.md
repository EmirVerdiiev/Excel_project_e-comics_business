#  Excel_project_e-comics_business
Comics App — Data Analysis Project

## Project Overview

This project focuses on analyzing data from a fictional digital comics reading platform. The goal is to explore user behavior, financial performance, and monetization patterns using data analysis techniques.
The project uses a synthetic relational dataset containing information about users, payments, refunds, reading activity, and marketing campaigns.

## Tools and Technologies

### SQL (MySQL)
Data querying, joins, aggregations, CTEs, window functions, and analytical calculations.

### Excel / WPS Spreadsheets
Data preparation, calculated columns, lookup functions, Pivot Tables, and reporting.

### Data Visualization
Charts and graphical representations of key business metrics.

### Project Objectives

The main objectives of the project are:

- Analyze user distribution across countries and device types.

- Calculate successful payments, refunds, and net revenue.

- Evaluate monetization metrics such as ARPU, ARPPU, and payer conversion rate.

- Analyze monthly revenue trends.

- Explore reading activity and user engagement.

- Evaluate marketing campaign performance.

## Data Analysis

The analysis covers several areas:

### 1. User Analysis

Exploring user distribution by country and device type, identifying paying users, and calculating payer conversion rates.

### 2. Revenue Analysis

Calculating total successful payments, refunded amounts, and net revenue. Comparing financial performance across countries and device types.

### 3. Monetization Metrics

Calculating Average Revenue Per User (ARPU) and Average Revenue Per Paying User (ARPPU) to evaluate user monetization.

### 4. Monthly Revenue Trends

Analyzing how revenue changes over time using monthly aggregations and line charts.

### 5. Reporting and Visualization

Creating Pivot Tables and charts to summarize business performance and make analytical results easier to interpret.

## Dataset

The project uses a synthetic dataset consisting of nine interconnected tables: users, payments, refunds, coin_packages, comics, episodes, reading_sessions, episode_unlocks, and campaigns.

The dataset contains no real customer information and is intended for educational and portfolio purposes.

# Project Purpose

This project demonstrates practical data analysis skills, including working with relational data, calculating business KPIs, transforming datasets, and presenting analytical results through spreadsheets and visualizations.
